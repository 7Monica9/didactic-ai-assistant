# Didactic AI Assistant: Automated Learning Architect

An intelligent tool designed to bridge the gap between complex technical documentation and actionable workplace training. Powered by **Google Gemini 1.5 Flash**.

## 🌟 Key Features
- **PDF Intelligence:** Converts unstructured machine manuals (e.g., CNC/Lathe) into structured guides.
- **Actionable Steps:** Automatically extracts 5 logical, sequential steps for immediate task execution.
- **Knowledge Validation:** Generates context-aware Multiple Choice Questions (MCQs) for instant feedback.
- **Multi-language Support:** Automatically adapts output language to match the input document (optimized for German/English).

## 🛠 Tech Stack
- **Language:** Python 3.x
- **Frontend:** Streamlit (Rapid prototyping)
- **LLM Engine:** Google Generative AI (Gemini 1.5 Flash)
- **PDF Processing:** PyPDF2

## ⚙️ Setup & Installation
1. Clone the repository: `git clone https://github.com/7Monica9/didactic-ai-assistant.git`
2. Install dependencies: `pip install streamlit google-generativeai PyPDF2`
3. Configure your API Key in the sidebar.
4. Run the app: `streamlit run didactic_ai.py`
